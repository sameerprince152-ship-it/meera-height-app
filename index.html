  3. Go to Project Settings → General → scroll down to Your apps → click Web (</>) → Copy the const firebaseConfig = { ... }; snippet.
  4. Paste the snippet or JSON below and click Connect Cloud Sync!

Config is stored securely in your browser's local storage and used directly to sync with your private Firestore.
